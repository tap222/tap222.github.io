# tapas mohanty · portfolio

Live: **https://tap222.github.io**

A single-file, framework-free portfolio. The hero is a 3D "embedding space" of projects; the ask box runs keyword retrieval over the project index in the browser and highlights the matches.

Focus areas: RAG, LLMs and agents, generative AI, MLOps and evals systems, production engineering (Kafka, Celery, BullMQ, OpenTelemetry), and ML at the edge.
