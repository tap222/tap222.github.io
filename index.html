i. LLMOps · evaluation

Assay

"Your prompt change broke 3 cases. Here's which ones, what changed, and whether it's real or noise"

Behavioral regression testing for AI apps and agents. Each test case is compared with its own last passing run, so a pull request shows exactly how the AI's behavior moved, not just a pass/fail count.

  • Behavior diffs: tool calls in order, cost, context, with a severity
  • Repeated attempts separate real regressions from chance, corrected for multiple checks
  • Judges calibrated against human labels, with bias and drift probes
  • A PR guard that refuses loosened assertions or skipped tests
  • Document-extraction metrics: fields, line items, tables, OCR, confidence gates
  • OpenTelemetry (OTLP) ingest: production traces become eval trajectories with no code changes

ii. document AI · GenAI in production

Folio

A document intelligence pipeline where every document is a state machine row

Scans come in; structured, verified records come out. One generic stage engine runs every step the same way: take a lock, run the worker, write the stage output, advance the status, queue the next stage. Scheduled jobs restart anything that stalls.

  • File prep → image pre-processing → OCR → classification → indexing → verification
  • Provider-neutral AI layer: Gemini on Vertex AI by default, Claude and Qwen per domain
  • FastAPI ingest, one Celery queue per stage, Beat for recovery and batch jobs
  • Postgres for state, Redis broker, object storage, Kafka events

iii. AIOps · agents · platform

Opswren

An AI operations platform: a request goes in, a verified change comes out

One work-item lifecycle for every request, incident and issue. The model is a replaceable worker; state, routing, evidence, approvals and verified outcomes belong to the runtime. Runs on a backend, an Android app and an iPhone app.

  • Prompt → AI plan → code edits on a branch → tests in a sandbox → diff for review
  • PR → human approval (policy engine) → merge → deploy → closed-loop verification
  • Infra monitoring turns alerts into incidents that verify and close themselves
  • Requests from GitHub, GitLab, Slack, Teams, email, WhatsApp and Sheets; results go back to the source
  • Bring your own model: Anthropic, OpenAI-compatible or Gemini keys
